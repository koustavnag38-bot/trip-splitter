# TripTogether: PWA + Android APK

This project now includes:

- A Progressive Web App (PWA) manifest, install prompt, icons, and service worker.
- A Capacitor Android build setup.
- A GitHub Actions workflow that creates a downloadable debug APK.

## 1. Deploy the website first

Deploy this Node.js project to an HTTPS host (for example Render) and configure the same Upstash Redis environment variables used by the server:

- `UPSTASH_REDIS_REST_URL`
- `UPSTASH_REDIS_REST_TOKEN`

Use a persistent shared database. Do not rely on the local `data/db.json` file for a hosted multi-user deployment unless the host provides persistent storage.

## 2. Install the PWA

After deployment, open the HTTPS website on Android Chrome. Use the **Install App** button if Chrome offers it, or choose the browser menu > **Install app** / **Add to Home screen**. On iPhone, open the site in Safari > Share > **Add to Home Screen**.

The service worker caches the app shell only. Login, account, and shared trip API calls always go to the live server; the app requires an internet connection for syncing and account actions.

## 3. Build an Android APK from GitHub

1. Push this project to GitHub.
2. Open the repository > **Settings** > **Secrets and variables** > **Actions** > **Variables**.
3. Click **New repository variable**.
4. Name it `TRIPTOGETHER_URL` and set its value to your deployed HTTPS website URL, for example `https://your-app.example.com` (use your real URL).
5. Save the variable.
6. Open the repository's **Actions** tab.
7. Select **Build TripTogether Android APK**.
8. Click **Run workflow** and confirm.
9. When the workflow completes, open that workflow run and download the **TripTogether-Android-APK** artifact.
10. Extract the downloaded artifact ZIP; it contains `app-debug.apk`.

The APK is a debug build suitable for testing and direct sharing. For a Play Store release, create a signed release build with a protected signing key; never commit the keystore or passwords to GitHub.

## Important

The Android wrapper loads the hosted HTTPS TripTogether website so the PWA and APK use the same backend and shared data. The APK therefore needs an internet connection. The APK is not generated by uploading HTML alone; GitHub Actions builds it using Capacitor and the Android toolchain.
